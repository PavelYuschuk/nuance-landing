# **PRD: Дизайн-система и архитектура сайта визитки "NUANCE" (v.1.1)** 

## **1. Стратегия и контекст** 

**Продукт:** Лендинг-портфолио тактической группы "NUANCE". 

**Цель:** Презентация состава команды, философии бренда и ключевых компетенций. 

**Архитектурный принцип:** Жесткая сетка, инженерная точность, концепция "единого механизма", утилитарная структура с тестированием нестандартных визуальных слоев. 

## **2. Дизайн-система (Токены)** 

### **2.1. Типографика** 

- **Заголовки (H1-H3):** Rajdhani. Вес: 600/700. Строго Uppercase.

- **UI, Субтитры:** Sofia Sans Semi Condensed. Вес: 500.

## **3. Архитектура блоков (Структура интерфейса)** 

### **3.1. Header (Глобальная навигация)** 

- **Семантика:** Логотип слева, якорные ссылки по центру, смена языка справа. Файл логотипа: Header.png. 

- **Визуал:** Высота 64px. Применяется эффект Glassmorphism (матовое стекло, backdrop-filter: blur). 

- **Интерактивность:** Фиксируется вверху (position: fixed). 

### **3.2. Hero-блок (Точка входа)** 

- **Семантика:** Центральный заголовок (Headline). 

- **Визуал:** min-height: 100vh. Текст выровнен по центру. На заднем плане — файл NUANCE logo.png с сильным размытием (blur) и радиальным градиентом от #141C29 к #0F0F0F. 

- **Интерактивность:** Отсутствие кнопок. 

### **3.3. Генезис (История)** 

- **Семантика:** Рассказ о происхождении группы на обломках старого комьюнити и переходе от масштаба к эффективности. 

- ● **Визуал:** Строгая 12-колоночная сетка. 

   - Левая зона (5 колонок): Текстовый блок (text-align: left). 

   - Правая зона (7 колонок): Изображение из файла About. Screen 1. 

### **3.4. Механизм (О нас / Структура / Философия)** 

- **Семантика:** Описание архитектуры взаимодействия, где уязвимость одного перекрывается сильными сторонами другого. 

- **Визуал:** Зеркальная 12-колоночная сетка (Z-паттерн). 

   - Левая зона (7 колонок): Иллюстрация/фото. 

   - Правая зона (5 колонок): Текстовый блок. 

### **3.5. Команда (Паттерн: Sticky Scroll + HUD Indicator)** 

- **Семантика:** Детальный разбор каждого члена группы с жесткой фиксацией структуры для удобства чтения. 

- **Визуал и Интерактивность:** 

- Блок получает position: sticky и height: 100vh. При вертикальном скролле контейнер фиксируется, а контент внутри него сменяется послойно (Scroll Variant). 

- **Сетка (Единая для всех слоев):** Строго: Слева текст (5 колонок), справа иллюстрация (7 колонок). Выравнивание текста только по левому краю. 

- **Навигационный трекер (Scroll Spy):** Индикатор в виде графического кольца-логотипа. 

- **Слой 1 (Presa4ek):** Акцент #C1FF00. В трекере горит левый сегмент кольца. 

- **Слой 2 (Art1zi):** Акцент #00E5FF. В трекере горит правый верхний сегмент кольца. 

- **Слой 3 (Matvi4):** Акцент #FFC107. В трекере горит правый нижний сегмент кольца. 

### **3.6. Проекты (Дисциплины)** 

- **Визуал:** Демонстрация профильных дисциплин. Фоновый файл: NUANCE logo.png (с эффектом blur). Поверх — сетка проектов с инженерными HUDэлементами. 

### **3.7. Call to Action (Социальные сети)** 

- **Визуал:** Симметричная композиция. Фоновый файл: NUANCE logo.png (четкий, без блюра). Слева и справа от центрального элемента — текстовые призывы и ссылки на ресурсы. 

### **3.8. Footer (Подвал)** 

- **Визуал:** Фоновый файл: NUANCE logo.png (опционально, с низким opacity) или строгий черный фон #0F0F0F. Минималистичный технический блок. Копирайт, юридическая информация. 

## **4. Адаптивность (Responsive Design)** 

### **4.1. Tablet (Планшеты, max-width: 1024px)** 

- **Сетка:** Трансформируется в 8 колонок. Базовый gap уменьшается до 16px. 

- ● **Типографика:** Базовый размер шрифта для заголовков H1-H3 масштабируется вниз на 20%. 

- **Команда:** Sticky Scroll сохраняется. Зоны ужимаются (текст — 4 колонки, иллюстрация — 4 колонки). 

### **4.2. Mobile (Смартфоны, max-width: 768px)** 

- **Сетка:** Строго 1 колонка (100% ширины), отступы (padding) 16px по бокам. 

- **Интерактивность:** ПОЛНОЕ ОТКЛЮЧЕНИЕ Sticky Scroll. На мобильных устройствах работает только стандартный вертикальный скролл. 

- **Команда:** Линейный вертикальный ритм. Выравнивание строго по левому краю: H3 (Имя) -> Иллюстрация -> Текст. 

- **Global HUD (Кольцо):** Трекер прогресса скрывается при мобильном скролле, чтобы не перекрывать полезную площадь экрана.
