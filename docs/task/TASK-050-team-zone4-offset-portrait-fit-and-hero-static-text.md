### 2.2. Расширение Ширины Zone 1 для 100% Заполнения по Высоте (`src/styles/team.css`)

Чтобы силуэт персонажа заполнил всю высоту блока от низа до верха, снимается горизонтальное зажатие колонки:

```css
/* =========================================================
   Zone 1: Расширение ширины без изменения высоты
   ========================================================= */

.team-zone-1 {
  position: relative;
  z-index: 2;
  height: 100%;
  
  /* Расширение ширины блока вправо: изображение свободно раскрывается во весь рост */
  width: 100%;
  min-width: 520px;
  overflow: visible;
  display: flex;
  align-items: flex-end;
  justify-content: flex-end;
}

.team-portrait-wrapper {
  position: relative;
  width: 100%;
  min-width: 520px;
  /* Высота остается прежней без изменений: */
  height: calc(100vh - clamp(140px, 18vh, 190px));
  max-height: 920px;
  display: flex;
  align-items: flex-end;
  justify-content: flex-end;
  bottom: 0;
}

/* Иллюстрация теперь занимает 100% высоты блока */
.player-portrait-img {
  position: absolute;
  bottom: 0;
  right: 0;
  height: 100%; /* Занимает всю высоту */
  width: auto;
  max-width: none; /* Снято ограничение по ширине, сжимавшее рост персонажа */
  object-fit: contain;
  object-position: right bottom;
  pointer-events: none;
}
```
