## 2. Инженерная Спецификация (Design Spec)

### 2.1. Монолитный Прогресс-бар (Monolithic Progressbar Track)
- **Контейнер трекера (`.about-progress-tracker`):**
  - `width: 100%; max-width: 320px` (или `100%` от ширин текстовой зоны `col-5`).
  - `height: 2px` (или `3px`).
  - `background: rgba(255, 255, 255, 0.12)`.
  - `position: relative; margin-top: 12px; margin-bottom: 32px; border-radius: 2px; overflow: hidden`.
- **Заполняющая линия (`.about-progress-fill` / `.tracker-progress-fill`):**
  - `position: absolute; top: 0; left: 0; height: 100%; width: 0%`.
  - `background: #FFFFFF` (с опциональным неоновым свечением `box-shadow: 0 0 8px rgba(255, 255, 255, 0.8)`).
  - `transition: width 0.1s cubic-bezier(0.25, 1, 0.5, 1)`.
- **Логика JS (`src/scripts/about-scroll.js`):**
  - При скролле секции `#genesis` значение `width` рассчитывается непрерывно от `0%` (начало 1-го слоя) до `100%` (конец 3-го слоя):
    - Слой 0 (0% – 33.3%)
    - Слой 1 (33.3% – 66.6%)
    - Слой 2 (66.6% – 100%)
