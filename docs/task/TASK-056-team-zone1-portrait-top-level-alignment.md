## 3. Инженерная Спецификация (Implementation Spec)

### 3.1. Локальный Подъем Zone 1 в Десктопной Сетке (`src/styles/team.css`)

Поскольку `.team-main-grid` является независимой CSS Grid сеткой, применение отрицательного верхнего отступа исключительно к колонке `.team-zone-1` поднимает только портрет персонажа, оставляя Zone 3 и Zone 4 абсолютно неподвижными.

Величина подъема: `52px (высота строки КОМАНДА) + 24px (margin-bottom подблока) = 76px`.

```css
/* =========================================================
   Zone 1: Подъем В УРОВЕНЬ с подблоком «КОМАНДА» (TASK-056)
   ========================================================= */

.team-zone-1 {
  position: relative;
  z-index: 2;
  height: 100%;
  width: 100%;
  min-width: 520px;
  overflow: visible;
  
  /* Старт от верхней границы: */
  display: flex;
  align-items: flex-start;
  justify-content: flex-end;
  
  background: transparent;
  border: none;
  box-shadow: none;

  /* Подъем верхнего края Zone 1 строго В УРОВЕНЬ с подблоком «КОМАНДА»: */
  margin-top: -76px;
}

.team-portrait-wrapper {
  position: relative;
  width: 100%;
  min-width: 520px;
  
  /* Высота от верхнего горизонта подблока «КОМАНДА» до низа секции: */
  height: calc(100vh - var(--header-height) - 36px);
  max-height: 960px;
  
  display: flex;
  align-items: flex-start;
  justify-content: flex-end;
  top: 0;
  bottom: auto;
  z-index: 2;
  overflow: hidden;
}

/* Иллюстрация заполняет контейнер от верхнего горизонта */
.player-portrait-img {
  position: absolute;
  top: 0;
  right: 0;
  height: 100%;
  max-height: 100%;
  width: auto;
  max-width: none;
```

### 3.2. Адаптивная Безопасность для Мобильных Устройств (`@media (max-width: 1024px)`)

В адаптивном брейкпоинте сетка переходит в вертикальный стек (`flex-direction: column`). Для исключения наложения слоев на планшетах и телефонах отрицательный марджин обнуляется:

```css
@media (max-width: 1024px) {
  .team-zone-1 {
    margin-top: 0; /* Безопасный вертикальный стек на планшетах и мобильных */
    min-width: 0;
  }
}
```
