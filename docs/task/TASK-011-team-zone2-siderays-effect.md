---

### 2.2. Конфигурационные Параметры Эффекта SideRays

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| `speed` | `1.2` | Скорость динамической анимации лучей |
| `rayColor1` | `#FCFDFF` | Базовый яркий цвет источника луча |
| `rayColor2` | `#94C6F9` | Вторичный спектральный цвет (с динамическим пресетом игрока) |
| `intensity` | `2.6` | Интенсивность свечения лучей |
| `spread` | `0.2` | Угол рассеивания пучка |
| `origin` | `"top-right"` | Источник испускания (верхний правый угол) |
| `tilt` | `60` | Угол наклона пучка лучей |
| `saturation` | `1.6` | Насыщенность тонов |
| `blend` | `0.86` | Коэффициент смешивания режимов наложения |
| `falloff` | `1.3` | Коэффициент затухания к краям |
| `opacity` | `0.4` | Прозрачность слоя над портретом |

---

### 2.3. Интеграция и Динамика при смене Персонажа (`src/scripts/side-rays.js`)
1. **Инициализация WebGL `ogl`:**
   - Создать модуль `src/scripts/side-rays.js`, использующий `Renderer`, `Program`, `Mesh`, `Triangle` из библиотеки `ogl`.
2. **Динамическая смена акцента `rayColor2`:**
   - При смене активного игрока параметр `rayColor2` в шейдере плавно анимируется под персональный акцентный цвет:
     - Presa4ek: `#C1FF00`
     - Art1zi: `#00E5FF`
     - Matvi4: `#FFC107`
3. **Оптимизация производительности:**
   - Ресайз-хэндлер для холста с подстройкой под `window.innerWidth` и `window.innerHeight`.
   - Остановка цикла `requestAnimationFrame` при выходе секции Команда из области видимости браузера (IntersectionObserver).
