# TASK-035: Калибровка Альфа-Маски Блюра в Секции 3.3 Генезис (Более Резкий и Компактный Переход)

**Status:** DONE  
**Target File(s):** `src/styles/genesis.css`  
**Parent Specification:** TASK-034 (`docs/task/TASK-034-hero-blur-removal-and-genesis-gradient-blur.md`)

## 1. Контекст и Цель Модификации
Калибровка параметров альфа-маски градиентного блюра (`gradient blur mask`) на верхней границе секции 3.3 «Генезис»:
1. **Уменьшение диапазона перехода:** Сокращение зоны перехода с растянутых 240px до компактных **60–80px**.
2. **Увеличение резкости (Sharper Ramp):** Более быстрое и собранное нарастание плотности размытия (от 0% до 100%) без эффекта размазанного тумана на треть экрана.

---

## 2. Инженерная Спецификация (Design Spec)

### 2.1. Обновленные Параметры Маски (`src/styles/genesis.css`)

В псевдоэлементе `.about-sticky-section::before` заменить градиент маски на компактный и резкий:

```css
/* =========================================================
   КАЛИБРОВАННЫЙ РЕЗКИЙ ГРАДИЕНТНЫЙ БЛЮР (TASK-035)
   ========================================================= */

.about-sticky-section::before {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  pointer-events: none;
  z-index: 1;
  
  /* Плотность размытия */
  backdrop-filter: blur(14px);
  -webkit-backdrop-filter: blur(14px);
  
  /* Компактный и резкий градиентный переход: всего 70px */
  mask-image: linear-gradient(
    to bottom,
    rgba(0, 0, 0, 0) 0px,
    rgba(0, 0, 0, 0.15) 15px,
    rgba(0, 0, 0, 0.85) 50px,
    rgba(0, 0, 0, 1) 70px,
    rgba(0, 0, 0, 1) 100%
  );
  -webkit-mask-image: linear-gradient(
    to bottom,
    rgba(0, 0, 0, 0) 0px,
    rgba(0, 0, 0, 0.15) 15px,
    rgba(0, 0, 0, 0.85) 50px,
    rgba(0, 0, 0, 1) 70px,
    rgba(0, 0, 0, 1) 100%
  );
}
```
