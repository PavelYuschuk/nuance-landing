## 1. Контекст и Цель Модификации
Глубокий рефакторинг визуального представления персонажей в секции "3.4. Команда":
1. Трансформация левой навигационной панели: увеличение высоты карточек в 2 раза (`~160px`), убирание квадратных аватарок, монолитное стыкование карточек без отступов (`gap: 0`), полноэкранный серый фоновый плейсхолдер с ником в левом нижнем углу.
2. Внедрение плавно растворяющейся неоновой полосы прогресса активного игрока под его именем (с акцентным цветом игрока: `#C1FF00`, `#00E5FF`, `#FFC107`).
3. Перевод всех показателей статистики игрока в интерактивные прогресс-бары формата: `[ Параметр ]` ➔ `[ Прогресс-бар ]` ➔ `[ Значение % ]`.
4. Удаление бейджа `[ STATUS: ACTIVE OPERATION ]`.
5. Обновление полного текстового контента (роли, цитаты, описание с нюансами) и всех параметров статов для каждого из 3-х персонажей.

## 2. Инженерная Спецификация (Design Spec)

### 2.1. Сетка и Левый Ростер Игроков (`.team-roster-nav` & `.roster-card`)
- **Контейнер навигации (`.team-roster-nav`):**
  - `display: flex; flex-direction: column; gap: 0; width: 100%` (Полное отсутствие отступов между блоками).
  - `border: 1px solid rgba(39, 53, 77, 0.4); border-radius: 8px; overflow: hidden`.
- **Карточка игрока (`.roster-card`):**
  - `height: 160px; width: 100%` (Увеличение высоты в 2 раза).
  - `position: relative; overflow: hidden; cursor: pointer`.
  - **Удален квадратный аватар (`.roster-card-avatar`):** Удален элемент превью.
  - **Фон карточки:** Серый фоновый плейсхолдер под будущую иллюстрацию:  
    `background: #1A2230; background-size: cover; background-position: center`.
    - Неактивная карточка: `filter: grayscale(100%) opacity(0.5); transition: filter 0.3s, opacity 0.3s`.
    - Активная карточка (`.active`): `filter: grayscale(0%) opacity(1)`.
- **Никнейм игрока (`.roster-card-name`):**
  - `position: absolute; left: 20px; bottom: 20px; z-index: 2`.
  - `font-family: var(--font-heading)` (`Rajdhani 700`), `font-size: 1.25rem`, `text-transform: uppercase`, `color: #FFFFFF`.
  - Все `.roster-card-name` выровнены по единому вертикальному уровню относительно низа своей карточки.

### 2.2. Затухающая Линия Прогресса Активного Игрока (Fading Progress Line)
- **Элемент индикатора под именем (`.roster-card-progress`):**
  - `position: absolute; left: 20px; bottom: 12px; height: 3px; width: 0%`.
  - `transition: width 0.4s cubic-bezier(0.16, 1, 0.3, 1)`.
- **Эффект постепенного растворения (Gradient Fade Out):**
  - `background: linear-gradient(to right, var(--player-accent) 0%, var(--player-accent) 50%, transparent 100%)`.
  - Или через CSS-маску: `mask-image: linear-gradient(to right, black 50%, transparent 100%)`.
- **Цветовая привязка акцентов:**
  - Presa4ek: `--player-accent: #C1FF00`
  - Art1zi: `--player-accent: #00E5FF`
  - Matvi4: `--player-accent: #FFC107`
- При активации карточки (`.active`) ширина индикатора дорастает до `80%`.

### 2.3. HUD Прогресс-бары Статистики (`.team-hud-grid` / `.team-stats-list`)
- **Формат отображения строки стата (`.stat-row`):**
  - `display: grid; grid-template-columns: 180px 1fr 60px; align-items: center; gap: 16px; margin-bottom: 12px`.
- **Элементы строки:**
  1. **Название параметра (`.stat-label`):** `font-family: var(--font-body)` (`JetBrains Mono 400`), `font-size: 0.85rem`, `color: #888888; text-align: left`.
  2. **Трек и заливка (`.stat-bar-track` & `.stat-bar-fill`):**
     - `.stat-bar-track`: `height: 6px; background: rgba(255, 255, 255, 0.08); border-radius: 3px; overflow: hidden; position: relative`.
