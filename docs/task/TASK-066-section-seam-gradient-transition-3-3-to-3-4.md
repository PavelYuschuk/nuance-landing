## 1. Контекст и Постановка Задачи

Пользователь предоставил скриншот с сайта World of Tanks (`media_1789075765924.png`) и поставил задачу:

> *«Изучи внимательно прикрепленный файл. На этом сайте я показал переход фона секций. По середине чтобы закрыть шов они осуществили это градиентом для плавного перехода. Необходимо сделать так же. Для теста осуществить такой переход между секцией `<!-- 3.3 Sticky Scroll Section -->` и `<!-- 3.4. Team Character Selector Section -->`»*

### 1.1. Анализ проблемы текущего «шва» (Hard Boundary Cutoff)
1. **Секция 3.3 (Genesis / О Нас):**  
   Имеет прозрачный фон (`background: transparent`), сквозь который просвечивает постоянный глобальный фон `.global-bg` (радиальный градиент `#141C29` $\to$ `#0F0F0F` + канонический логотип NUANCE).
2. **Секция 3.4 (Team Character Selector):**  
   Имеет автономный фоновый слой `Zone 0` (`.team-zone-0`), содержащий сплошную заливку `#0F0F0F`, фотографические арты окружения игроков (`background_presaek.png`, `background_Art1zi.png`, `background_matvi4.png`) и радиальный оверлей 90% непрозрачности (`.team-zone-0::after`).
3. **Возникновение шва:**  
   При прокрутке страницы в момент смены секций верхний край Секции 3.4 входит в область видимости снизу экрана с жесткой, резкой горизонтальной границей по пиксельной линии `Y=0`. Из-за наличия текстуры фотографии и разницы в распределении яркости этот переход воспринимается как грубый «срез» фона, разрушающий кинематографическую целостность интерфейса.

## 2. Анализ Референса World of Tanks (`media_1789075765924.png`)

В референсном интерфейсе переход между двумя контрастными сюжетными блоками (верхний блок с портретами стримеров в теплом ореоле и нижний блок ангара с танками в холодно-синей гамме) решен через **двухсторонний градиентный мост (Dual-ended Gradient Seam Bridge)**:
1. **Нижний край верхней секции:** Плавно затухает книзу в глубокий базовый цвет фона, избавляясь от любых резких краев контента и подложки.
2. **Верхний край нижней секции:** Начинается не резко, а плавно проявляется сверху вниз из того же базового темного цвета через широкий градиентный переход (высотой ~250–320px).
3. **Точка стыка (шов):** На физической границе между секциями оба фона сходятся в единый монолитный цвет `#0F0F0F`. В результате линия стыка физически исчезает — между секциями образуется единый бесшовный переход («закрытый шов»).

## 3. Архитектура и Математика Реализации в NUANCE

Для достижения идеальной шелковистой плавности переход формируется из двух согласованных слоев на границе секций:

### 3.1. Верхний Градиентный Мост в Секции 3.4 (`Zone 0 Top Blend`)
Внутри `.team-zone-0` реализуется связка из двух механизмов:
1. **Сплайновый градиентный оверлей (`.team-zone-0::before`):**  
   Располагается в верхней части зоны фона с `z-index: 3` (над фото персонажей и над радиальным затемнением, но строго под текстовым контентом и карточками ростера).
   - Высота: `clamp(200px, 26vh, 340px)`.
   - Градиентная кривая: нелинейная сплайновая интерполяция (Cubic Easing), предотвращающая эффект цветовых полос (Mach banding effect).
2. **Альфа-маска для фото-слоев (`.team-bg-layer`):**  
   Для устранения даже 1% жесткой границы растровой текстуры самого изображения на `.team-bg-layer` накладывается верхняя градиентная маска `mask-image: linear-gradient(...)`, плавно растворяющая картинку в прозрачность к верхнему краю:
   $$A(y) = 0 \quad \text{при } y = 0 \text{ px}, \quad A(y) = 1 \quad \text{при } y \ge 280 \text{ px}$$

### 3.2. Нижний Затухающий Шлейф в Секции 3.3 (`Genesis Bottom Vignette`)
На `.about-sticky-viewport` добавляется псевдоэлемент `::after`:
- Располагается вдоль нижней границы viewport (`bottom: 0`).
- Высота: `clamp(160px, 20vh, 260px)`.
- Направление: `linear-gradient(to bottom, transparent 0%, rgba(15,15,15,0.95) 85%, #0F0F0F 100%)`.
- Обеспечивает мягкое погружение контента и фона Секции 3.3 в цвет `#0F0F0F` к моменту наката Секции 3.4.

### 3.3. Математическое Доказательство Исчезновения Шва
$$\lim_{y \to Y_{\text{seam}}^-} C_{\text{Genesis}}(y) = \#0F0F0F$$
$$\lim_{y \to Y_{\text{seam}}^+} C_{\text{Team}}(y) = \#0F0F0F$$
$$\Delta C = |C_{\text{Genesis}} - C_{\text{Team}}| = 0$$
Разница цветов на границе равна нулю, граница оптически аннулируется.
