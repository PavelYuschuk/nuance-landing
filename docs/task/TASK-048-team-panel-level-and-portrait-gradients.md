## 1. Контекст и Инженерная Задача
1. **Подъем Zone 4 на уровень подблока «Команда»:**  
   Устранение смещения вниз для центральной информационной панели (`Zone 4: Center Info Panel`). Заголовок имени игрока (`<h2 class="team-player-name">`) выравнивается строго на одну горизонтальную линию с подблоком текста `КОМАНДА` (`.team-header-subblock`).
2. **Ослабление нижнего градиента портрета в 2 раза:**  
   Уменьшение интенсивности (прозрачности) и высоты нижнего затемняющего градиента на слое иллюстрации (`Zone 1`) ровно на **50%** (в 2 раза меньше и мягче).
3. **Временный верхний градиент портрета:**  
   Добавление мягкого затухающего градиента в верхней части иллюстрации персонажа для плавного списания макушки силуэта в темноту фона.

### 2.2. Ослабленный Нижний и Новый Верхний Градиент Портрета (`Zone 1`)

Внедрение двухстороннего мягкого виньетирования (Dual Soft Fade) на контейнере портрета:

```css
/* =========================================================
   Zone 1: Двойной градиент портрета (TASK-048)
   ========================================================= */

.team-portrait-wrapper {
  position: relative;
  width: 100%;
  height: calc(100vh - clamp(140px, 18vh, 190px));
  max-height: 920px;
  display: flex;
  align-items: flex-end;
  justify-content: flex-end;
  bottom: 0;
  overflow: hidden;
}

/* Оверлей двойного градиента: 
   - Сверху: мягкое затухание (70px, 45% плотности)
   - Снизу: уменьшен в 2 раза (70px вместо 150px, 45% плотности вместо 95%) */
.team-portrait-wrapper::after {
  content: '';
  position: absolute;
  inset: 0;
  pointer-events: none;
  z-index: 3;
  background: linear-gradient(
    to bottom,
    rgba(15, 15, 15, 0.45) 0px,         /* Верхний градиент: 45% */
    transparent 70px,                   /* Окончание верхнего градиента */
    transparent calc(100% - 70px),      /* Чистая средняя зона иллюстрации */
    rgba(15, 15, 15, 0.45) 100%         /* Нижний градиент: уменьшен в 2 раза */
  );
}

/* Дублирующая мягкая альфа-маска непосредственно для изображения */
.player-portrait-img {
  position: absolute;
  bottom: 0;
  right: 0;
  height: 100%;
  max-height: 100%;
  width: auto;
  object-fit: contain;
  object-position: right bottom;
  pointer-events: none;
  z-index: 2;
  
  /* Мягкая растушевка краев в 2 раза деликатнее прежней */
  mask-image: linear-gradient(
    to bottom,
    rgba(0, 0, 0, 0.55) 0px,
    rgba(0, 0, 0, 1) 60px,
    rgba(0, 0, 0, 1) calc(100% - 60px),
    rgba(0, 0, 0, 0.55) 100%
  );
  -webkit-mask-image: linear-gradient(
    to bottom,
    rgba(0, 0, 0, 0.55) 0px,
    rgba(0, 0, 0, 1) 60px,
    rgba(0, 0, 0, 1) calc(100% - 60px),
    rgba(0, 0, 0, 0.55) 100%
  );
}
```
