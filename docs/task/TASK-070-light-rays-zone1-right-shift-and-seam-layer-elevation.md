## 2. Анализ и Инженерные Решения

### 2.1. Пункт 1: Возможность и Реализация Смещения LightRays Вправо над Zone 1
* **Технический вердикт:** **Да, абсолютно реализуемо.**
* **Геометрическое позиционирование:**  
  В 12-колоночной сетке Секции 3.4:
  - `Zone 3` (Ростер): Колонки 1–3 (0% – 25% ширины).
  - `Zone 4` (Инфо-панель): Колонки 4–8 (25% – 66.7% ширины).
  - `Zone 1` (Портрет бойца): Колонки 9–12 (66.7% – 100% ширины, центр колонки находится на координате **$X \approx 78\%$**).
* **Причина центрального расположения в TASK-069:**  
  Изначально в свойствах шейдера действовал дефолт `raysOrigin: 'top-center'` ($X = 50\%$), из-за чего поток лучей падал на центральный текст `Zone 4`.
* **Решение:**  
  В функции расчета опорной точки шейдера `getAnchorAndDir()` вводится калиброванная точка привязки `'top-zone1'`:
  $$\text{anchor} = [0.78 \times w, -0.2 \times h], \quad \text{dir} = [-0.08, 1.0]$$
  Свет падает прямо из верхней зоны над головой оперативника со слабым естественным наклоном внутрь композиции ($-0.08$), мягко очерчивая силуэт персонажа объемным кинематографическим светом (Rim Light / God Rays). При этом ширина холста остается полноэкранной, исключая обрезание лучей рамками колонок.

---

### 2.2. Пункт 2: Подъем Градиентного Шва Слоем Выше LightRays
* **Первопричина перекрытия в TASK-069:**  
  Градиентный шов создавался через `.team-zone-0::before`. Но сам элемент `.team-zone-0` имеет `z-index: 1`.  
  В CSS дочерний псевдоэлемент `::before` не может выйти за рамки контекста наложения своего родителя.  
  Слой WebGL-лучей `.team-zone-2` обладал `z-index: 2`, из-за чего WebGL-холст отрисовывался **поверх** верхнего затемняющего градиента, и лучи пробивали шов на границе с Секцией 3.3.
* **Решение:**  
  Градиентный шов переносится на общий родительский контейнер вьюпорта — **`.team-sticky-viewport::before`** с присвоением **`z-index: 3`**:

```
┌──────────────────────────────────────────────────────────────┐
│ .team-container (Текст, Ростер, Портрет)        [z-index: 4] │
├──────────────────────────────────────────────────────────────┤
│ .team-sticky-viewport::before (ГРАДИЕНТНЫЙ ШОВ) [z-index: 3] │ ◄── НАД ЛУЧАМИ!
├──────────────────────────────────────────────────────────────┤
│ .team-zone-2 (WebGL LightRays над Zone 1)       [z-index: 2] │
├──────────────────────────────────────────────────────────────┤
│ .team-zone-0 (Базы + 90% Оверлей)               [z-index: 1] │
└──────────────────────────────────────────────────────────────┘
```

В результате:
1. WebGL-лучи струятся над Zone 1 на уровне `z-index: 2`.
2. Градиентный шов на уровне `z-index: 3` плавно, бесшовно и мягко гасит верхний край световых лучей в базовый тон `#0F0F0F`, предотвращая любой жесткий срез или засветку на стыке с Секцией 3.3.
3. Контент секции (`z-index: 4`) остается полностью контрастным.

## 3. Техническая Спецификация Изменений

### 3.1. Изменения в `src/scripts/light-rays.js`

В функции `getAnchorAndDir(origin, w, h)` добавляется пресет `'top-zone1'`:

```javascript
const getAnchorAndDir = (origin, w, h) => {
  const outside = 0.2;
  switch (origin) {
    case 'top-left':
      return { anchor: [0, -outside * h], dir: [0, 1] };
    case 'top-right':
      return { anchor: [w, -outside * h], dir: [-0.2, 1] };
    case 'top-zone1': // TASK-070: Смещение источника лучей строго над Zone 1 (колонки 9-12)
      return { anchor: [0.78 * w, -outside * h], dir: [-0.08, 1] };
    case 'left':
      return { anchor: [-outside * w, 0.5 * h], dir: [1, 0] };
    case 'right':
      return { anchor: [(1 + outside) * w, 0.5 * h], dir: [-1, 0] };
    case 'bottom-left':
      return { anchor: [0, (1 + outside) * h], dir: [0, -1] };
    case 'bottom-center':
      return { anchor: [0.5 * w, (1 + outside) * h], dir: [0, -1] };
    case 'bottom-right':
      return { anchor: [w, (1 + outside) * h], dir: [0, -1] };
    default: // "top-center"
      return { anchor: [0.5 * w, -outside * h], dir: [0, 1] };
  }
};
```
