## 1. Контекст и Цель Модификации
Обновление настроек шейдера WebGL-эффекта **SideRays** в спецэффектном слое **Zone 2 (`.team-zone-2`)** секции "3.4. Команда".Изменения направлены на замедление динамики движения, расширение угла рассеивания лучей и повышение плотности прозрачности.

## 2. Инженерная Спецификация (Design Spec)

### 2.1. Сравнительная Матрица Параметров Шейдера SideRays

| Параметр | Старое значение (TASK-011) | Новое значение (TASK-012) | Влияние на визуал |
| :--- | :--- | :--- | :--- |
| **`speed`** | `1.2` | **`0.2`** | Более плавное, неспешное плавание лучей |
| **`rayColor1`** | `#FCFDFF` | **`#FCFDFF`** | Белоснежное ядро светового потока |
| **`rayColor2`** | `#94C6F9` | **`#94C6F9`** | Небесно-голубой отпенок рассеивания |
| **`intensity`** | `2.6` | **`2.0`** | Мягкая интенсивность свечения |
| **`spread`** | `0.2` | **`1.2`** | Широкий угол размаха пучка лучей |
| **`origin`** | `"top-right"` | **`"top-right"`** | Источник испускания в верхнем правом углу |
| **`tilt`** | `60` | **`60`** | Угол наклона падения лучей 60° |
| **`saturation`**| `1.6` | **`1.5`** | Естественная насыщенность тонов |
| **`blend`** | `0.86` | **`1.0`** | 100% плотность наложения на фон |
| **`falloff`** | `1.3` | **`1.4`** | Усиленный коэффициент затухания краев |
| **`opacity`** | `0.4` | **`0.65`** | Повышенная контрастность и видимость слоя |
