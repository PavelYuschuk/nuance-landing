## 2. Инженерная Спецификация (Design & Code Spec)

### 2.1. Кинематика Ухода Текста и Логотипа перед Секцией 3.4 (`src/scripts/about-scroll.js`)

В обработчик скролла секции 3.3 («Генезис») добавляется расчет выхода (Exit Phase):

```javascript
// Внутри функции скролла about-scroll.js:
const genesisSection = document.getElementById('genesis');
const globalBgLogo = document.querySelector('.global-bg-logo');
const heroTextWrapper = document.querySelector('.hero-left-content, .hero-monolith-wrapper');

function handleGenesisScroll() {
  const rect = genesisSection.getBoundingClientRect();
  const windowHeight = window.innerHeight;

  // 1. Пока пользователь находится в Hero или скроллит слои 3.3 (rect.bottom >= windowHeight):
  // Логотип и текст остаются зафиксированными на своих базовых координатах
  if (rect.bottom >= windowHeight) {
    if (globalBgLogo) {
      globalBgLogo.style.transform = 'translateY(-50%)';
    }
    if (heroTextWrapper) {
      heroTextWrapper.style.transform = 'translateY(0)';
    }
  } 
  // 2. Когда 3.3 завершает показ слоев и уходит вверх к Секции 3.4 (rect.bottom < windowHeight):
  // Логотип и Текст синхронно сдвигаются вверх вместе со скроллом:
  else {
    const exitOffset = windowHeight - rect.bottom;
    if (globalBgLogo) {
      globalBgLogo.style.transform = `translateY(calc(-50% - ${exitOffset}px))`;
    }
    if (heroTextWrapper) {
      heroTextWrapper.style.transform = `translateY(-${exitOffset}px)`;
    }
  }
}

window.addEventListener('scroll', handleGenesisScroll, { passive: true });
if (window.lenisInstance) {
  window.lenisInstance.on('scroll', handleGenesisScroll);
}
```
